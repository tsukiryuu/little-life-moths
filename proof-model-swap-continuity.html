Continuity Through Model Configuration Change

Persistent-agent systems increasingly separate durable history from whichever model is currently used for inference. We tested one narrow version of that separation locally.

Letta-local result

On an isolated local Letta backend, we changed only the configured model field between two provider/model identifiers. No model turn was executed.

  • configured model field changed
  • durable memory content hash stayed unchanged
  • MemFS Git head stayed unchanged
  • system prompt stayed unchanged

This supports a storage/continuity property only. It is not evidence of metaphysical identity persistence, equivalent model behavior, or production migration safety.
